# Ultimate Gun Shop — Deployment Package

Static HTML demo prepared for GitHub + Vercel deployment. Includes the supplied homepage, reference assets, and a customer review section using the excerpts provided.

## Before publishing
- Verify the business details and every link with the owner.
- Verify each review's actual Google star rating before publishing star symbols as ratings.
- Confirm you have permission to use the supplied photographs and graphics.
- Test all buttons and external links on mobile and desktop.

## Deploy
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload `index.html`, the `assets/` folder, and this README at the repository root.
4. Import the repository in Vercel and deploy as a static HTML site. No build command is required; use `.` as the output directory if prompted.
5. In Vercel Project Settings → Domains, add the new domain and follow the DNS records Vercel provides.
6. Test the preview and custom domain after DNS/HTTPS setup.

This ZIP does not create a GitHub repository or deploy/configure the domain automatically.
