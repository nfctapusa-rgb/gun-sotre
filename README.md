# Ultimate Gun Shop

Static HTML demo package for Ultimate Gun Shop in Montebello, California.

## Deploy with Vercel

1. Extract `ultimate-gun-shop-deploy.zip` on your computer.
2. Upload the extracted `index.html`, `assets/` folder, and `README-DEPLOY.md` to the root of this repository. The ZIP alone is not a Vercel-ready root site.
3. In Vercel, create a new project and import `nfctapusa-rgb/gun-sotre`.
4. Use no build command and set the output directory to `.` for a static HTML deployment.
5. Add your custom domain in Project Settings → Domains and follow the DNS instructions Vercel gives you.

Verify all business details and customer review ratings before publishing.
